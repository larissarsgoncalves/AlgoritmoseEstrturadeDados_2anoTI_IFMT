# ATIVIDADES DA DISCIPLINA DE ALGORITMOS E ESTRUTURAS DE DADOS - IFMT CAMPUS CAMPO VERDE
2025

EXERCICIOS QUE DEVEM CONTEM:
1. Escreva um programa que exiba a mensagem: "Bem-vindo ao mundo Python!" Dica: Use o comando print.
2. Crie um programa que peça ao usuário para digitar seu nome e idade, e exiba: "Olá, {nome}! Você tem {idade} anos."
3. Desenvolva um programa que leia dois números inteiros e exiba a soma, a subtração e a multiplicação deles. (Lembre-se de converter os valores lidos com int().
4. Escreva um programa que peça ao usuário um número e use if para determinar se é par ou ímpar.
5. Peça ao usuário um número e use if para verificar se ele é positivo, negativo ou zero.
6. Crie um programa que solicite a idade do usuário e use if para verificar se ele é maior de idade (18 anos ou mais).
7. Escreva um programa que receba dois números e uma operação (adição, subtração, multiplicação ou divisão). Use if para realizar a operação correta com base na escolha do usuário.
8. Crie um programa que peça ao usuário um nome de usuário e senha e use if para verificar se as credenciais estão corretas.
9. Peça ao usuário uma temperatura e use if para determinar se está "frio“(<20), "morno“(>20 e <26) ou "quente“(>27) com base em intervalos de valores.
10. Crie um programa que peça o valor da compra e use if para calcular o desconto baseado em faixas de preço (exemplo: compras acima de R$100 ganham 10% de desconto).
11. Faça um algoritmo que realize o cadastro de uma pessoa, a senha deve ter no minimo 8 caracteres. O email cadastrado deve estar todo minusculo, depois solicite o login com os dados cadastrados.
12. Um banco deseja diminuir a quantidade de contas ativas sem saldo do seu sistema. Desenvolva um algoritmo que verifique o saldo da conta ( solicite essa info ao responsavel pelo acesso) se o saldo for 0 alterar o status da conta para inativo.
